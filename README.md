The reason the HTML file is really split into two sections would be because it would be easier to interact with when we know that one part is the navigation while the other part is where the movies are displayed. Making that distinction early on helps us with the individual changes that we don't want to affect the entire page, rather just one of the sections. It's even better considering we can have even more sections inside each section to really hone and refine what we want to fix. The reason the grid was chosen over Flex box was because, on a normal movie website, having the movies be displayed at varying sizes and varying distances would've been awkward to visualize and see. We went with a grid because not only can we guarantee that each of the movies would be in their own space, we can also ensure they would be evenly spaced and represented.
